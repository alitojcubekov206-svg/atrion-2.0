# Состояние риггинга и генерации персонажей

Последнее указание пользователя: риггинг отложен. Текущий этап — текстовый AI для 3D и генерация редактируемого дома. История предыдущих этапов ниже сохраняется.

## Текстовый AI и дом — текущий этап

Локальная конфигурация Cloudflare теперь используется и для текстового AI. Сохранён приоритет прежних текстовых ключей, добавлены явный выбор/отключение провайдера, проверка обрезанных ответов, JSON Schema и общий бюджет времени. Реальный запрос к Workers AI выполнен; наличие ключей на production не проверено.

Генерация 3D больше не заменяет валидную AI-геометрию шаблоном из-за числа деталей/score и не подгоняет её под размеры baseline. Однодетальная модель допустима; размеры, некорректные примитивы и совпадающие повторения проверяются отдельно. Убрано требование добавлять крыши/рамы и больше деталей при исправлении. Эти изменения относятся к первичной генерации; старый AI refine требует отдельной проверки качества.

Дом: приватный генератор извлекает запрошенные комнаты/размеры, AI назначает доли площади, алгоритм делит контур и создаёт дверные проходы. Реальный запрос на 12×9 м с прихожей, кухней-гостиной, двумя спальнями и санузлом сохранил все пять помещений, белые стены и плоскую крышу. Проверены общий parser, площадь 108 м², покрытие без пересечений, связность, открытие в редакторе, undo/redo импорта и скачивание GLB. Дом имеет 43 mesh; файл 87 280 байт повторно прочитан GLTFLoader. JSON/GLB и скриншот проверки остаются локальными, без секретов.

Проверки текущего кода: 72/72 backend-теста; 13/13 тестов AI-геометрии; TypeScript и production build прошли; procedural gen-report выполнен на 26 запросах. Он не измеряет соответствие AI-модели заданию. Проверено отсутствие сетевых повторов при лимите и возврат квоты дома при ошибке/отмене; реальная база не использовалась.

Ограничения подтверждены реальными испытаниями: AI всё ещё ошибается в расположении/числе компонентов и размерах 3D. Ракета и стол дали читаемые GLB, но не прошли полную приёмку качества: у ракеты совпадали повторения, у стола высота отклонилась от задания. У дома проверка программы уменьшает пропуски, но само извлечение требований тоже может ошибаться. Двери могут вести через жилые комнаты; алгоритм связности не заменяет архитектурное проектирование. Лестницы и интерьер не добавлены. Unity Editor, авторизованный UI → API → БД и production deployment не проверены.

Дата: 5 октября 2026 года, Asia/Bishkek. Основа — `main` / `26ea85d9f9a4c76cc314e30a105664af7a7cf1f0` репозитория `alitojcubekov206-svg/atrion-2.0`. Перед публикацией remote повторно проверен. Рабочая ветка — `codex/backend-rigging`.

## Реализовано

После серверного этапа пользователь разрешил интерфейсы 2D/3D-риггинга. Затем уточнил главный сценарий: генерация персонажа и готового рига по тексту уровня Live2D-примера. Этот сценарий пока не реализован; подробности — [CHARACTER_GENERATION.md](CHARACTER_GENERATION.md). Добавлены серверные контракты версии 1 и вычисления 2D FK/keyframes, жёсткого 3D FK и дома из прямоугольных комнат/проёмов. Добавлены приватные API вычисления, CRUD и JSON-экспорта, Prisma `DesignDocument`, revision/ownership и технические лимиты. Подробности — [DESIGN_BACKEND.md](DESIGN_BACKEND.md).

Добавлены ручные редакторы `/dashboard/rigging`, dev-only `/playground/rigging`, shared FK/контракты, Canvas 2D, кости поверх 3D, undo/redo, JSON с встроенными PNG/WebP, сохранение pose и статический GLB. Удаление/перепривязка кости сохраняют положение слоёв/деталей. 2D-кость создаётся двумя точками на холсте; 3D-камера подстраивается под модель. Детали — [RIGGING_EDITOR.md](RIGGING_EDITOR.md).

Явные 2D/Live2D/VTuber-запросы не попадают в генератор примитивов. UI переносит описание в форму первого этапа генерации рисунка; внешний запрос запускает отдельная кнопка. Добавлены auth, AI-квота с возвратом, проверка ответа и скачивание рисунка. Результат явно обозначен как рисунок без рига. `.github/CODEOWNERS`, package-lock и старый геометрический генератор сохранены. 3D skinning, объектное хранение больших ассетов, анимационный GLB, лестницы и инженерные расчёты не реализованы.

Предыдущий этап подготовил русские документы, три проектных skills и конфигурацию официального OpenAI Docs MCP. Конфигурация относится к разработке, а не runtime приложения. Skills применены к этому серверному этапу.

## Проверки

Этап полного роста: локальный мастер собирает 14 костей и weighted mesh, доступны FK-drag и клипы дыхания, приветствия и покачивания. На реальном рисунке проверены подготовка JPEG, удаление белых просветов, настройка колен, проигрывание/пауза/переход к ключу, поворот предплечья, один undo после drag, импорт/экспорт изображения с сеткой. Повреждённый JSON с неизвестной костью веса отклоняется без замены текущей работы. Найдено и исправлено перетягивание соседней стопы: аналитическая проверка конечного артефакта даёт нулевое смещение правой ноги при движении левой; исправленная поза также отображена в локальном preview. Итоговый пример: 415 вершин, 646 треугольников, встроенный WebP и три clips, около 131 KB JSON. Файл и рисунок остаются локальными и исключены из Git.

Во время повторной браузерной проверки старое нативное подтверждение замены зависло в автоматизации. Новая сборка рига теперь сохраняет предыдущую работу в undo и не вызывает это подтверждение. Отдельный путь локального fixture проверен отображением итогового JSON; последняя сборка/типы прошли. Сквозная генерация через авторизованную страницу и реальную БД по-прежнему не проверена.

## Ограничения

Новая таблица не применялась к рабочей базе; production, Vercel, доставка Brevo и оплата не проверялись. Сохранение/переоткрытие через реальную PostgreSQL-базу требует отдельной staging-проверки после применения DDL. HTTP-проверка без сессии не доказывает успешный CRUD авторизованного пользователя. Серверное сохранение из UI без реальной PostgreSQL не проверено. Cloudflare настроен локально и проверен реальным вызовом серверного адаптера. JPEG 1024×1024, 291 587 байт успешно декодирован. Первое изображение не прошло требования полного роста/A-позы. Следующий реальный запрос дал JPEG 1024×1024, 187 779 байт: видны кисти и ступни, руки разнесены; этот рисунок подготовлен для 2D skin-рига. OpenAI, авторизованный полный путь UI/API/БД и отмена реального запроса не проверены. Данные доступа остаются в исключённом из Git .env.local; генератор Live2D отсутствует. Архив пользователя исследован по JSON и текстурам, но его движение в Cubism runtime не проигрывалось.

В старой копии `C:\Users\user\Projects\Atrion 2.0` имеются незавершённые пользовательские изменения генератора/shared и новые interior/rig-файлы. Эта копия не изменялась и её код не переносился. Старый HEAD — `425962591fa60ba7079300178a063314395a8f9c`.

GitHub plugin подтверждает доступ к репозиторию. Работа публикуется отдельной веткой и draft PR; merge, deployment и изменения production-схемы в этот этап не входят. OpenAI Docs MCP ранее проверен через initialize/tools-list/search; подробности — [TOOLING.md](TOOLING.md).

## Параметры и keyforms деформеров — 5 октября 2026

Добавлены параметры с диапазонами, ключевые формы Warp/Rotation, ползунок смешивания, parameter tracks с linear/step и цикл анимации. Общий evaluator используется сервером и Canvas; явные overrides параметров валидируются. Один параметр на деформер; независимые движения комбинируются вложенностью.

В браузере проверены создание трёх форм поворота, запуск цикла, переход к ключам, замена/удаление ключа и отмена удаления, скачивание JSON и повторный импорт. Скачанный файл содержит три формы и трек 0→2→4 секунды; общий parser/evaluator подтвердил изменение геометрии 415 вершин при сохранении UV. 60/60 тестов, TypeScript и production build прошли. Автоматические тесты дополнительно проверяют аналитическую интерполяцию, loop/clamp/step, независимость от FPS, сериализацию и запрет складывания Warp между валидными крайними формами.

Прямые keyforms вершин/opacity, многомерное смешивание, готовые глаза/рот и физика пока не реализованы. Реальное серверное сохранение остаётся непроверенным без локальной БД; production не обновлялся.
