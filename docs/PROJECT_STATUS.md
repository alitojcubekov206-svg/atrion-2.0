## Реализовано

По прямому запросу пользователя начата реализация в GitHub без изменений фронтенда. Добавлены серверные контракты версии 1 и вычисления 2D FK/keyframes, жёсткого 3D FK и дома из прямоугольных комнат/проёмов. Добавлены приватные API вычисления, CRUD и JSON-экспорта, Prisma `DesignDocument`, revision/ownership и технические лимиты. Подробности — [DESIGN_BACKEND.md](DESIGN_BACKEND.md).

Существующие `src/frontend/`, страницы/layouts, `src/shared/`, `.github/CODEOWNERS`, package-lock и старые генераторы не изменены. Новый UI отсутствует. Skinning, бинарное хранение ассетов, анимационный GLB, лестницы и инженерные расчёты не реализованы.

Предыдущий этап подготовил русские документы, три проектных skills и конфигурацию официального OpenAI Docs MCP. Конфигурация относится к разработке, а не runtime приложения. Skills применены к этому серверному этапу.

## Проверки

- `npm run test:backend`: 25/25. Аналитические FK/pivots, bind reset, интерполяция/loop/full turns, affine shear, repeat/mirror/mesh, валидация, реальные проёмы, общие стены с десятичными координатами, JSON round trip и потоковый UTF-8/лимит тела.
- Unit-проверки хранения с подменённым Prisma-клиентом: фильтры владельца, stale revision, неизменяемый kind, блокировка User перед подсчётом cap и отказ до create. Реальные PostgreSQL-транзакции/конкурентные запросы ими не проверены.
- HTTP smoke в production-режиме: все 8 новых операций без сессии вернули 401, без записи в БД; временный сервер остановлен.
- `npx tsc --noEmit` и `npm run build` прошли; build включает `prisma generate` и новые Route Handlers. Проверки включены в CI на Node 22; локальная среда — Node 24.
- `gen-report.ts`: 26 запросов, 26 различных моделей, средний score 0.93, минимальный 0.611. Это диагностика существующего генератора, не визуальная приёмка.
- `csg-smoke.ts`: union/subtract/intersect завершились; есть существующее предупреждение MeshBVH о deprecated maxLeafTris.
- `voice-test.ts`: распознано 52/52 команды.
- Документационные пути/ссылки и `git diff --check` проверены. Три навыка ранее прошли quick_validate.py; имена и YAML интерфейса согласованы.
