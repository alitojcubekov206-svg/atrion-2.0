# Состояние риггинга и генерации персонажей

Дата: 5 октября 2026 года, Asia/Bishkek. Основа — `main` / `26ea85d9f9a4c76cc314e30a105664af7a7cf1f0` репозитория `alitojcubekov206-svg/atrion-2.0`. Перед публикацией remote повторно проверен. Рабочая ветка — `codex/backend-rigging`.

## Реализовано

После серверного этапа пользователь разрешил интерфейсы 2D/3D-риггинга. Затем уточнил главный сценарий: генерация персонажа и готового рига по тексту уровня Live2D-примера. Этот сценарий пока не реализован; подробности — [CHARACTER_GENERATION.md](CHARACTER_GENERATION.md). Добавлены серверные контракты версии 1 и вычисления 2D FK/keyframes, жёсткого 3D FK и дома из прямоугольных комнат/проёмов. Добавлены приватные API вычисления, CRUD и JSON-экспорта, Prisma `DesignDocument`, revision/ownership и технические лимиты. Подробности — [DESIGN_BACKEND.md](DESIGN_BACKEND.md).

Добавлены ручные редакторы `/dashboard/rigging`, dev-only `/playground/rigging`, shared FK/контракты, Canvas 2D, кости поверх 3D, undo/redo, JSON с встроенными PNG/WebP, сохранение pose и статический GLB. Удаление/перепривязка кости сохраняют положение слоёв/деталей. 2D-кость создаётся двумя точками на холсте; 3D-камера подстраивается под модель. Детали — [RIGGING_EDITOR.md](RIGGING_EDITOR.md).

Явные 2D/Live2D/VTuber-запросы не попадают в генератор примитивов. UI переносит описание в форму первого этапа генерации рисунка; внешний запрос запускает отдельная кнопка. Добавлены auth, AI-квота с возвратом, проверка ответа и скачивание рисунка. Результат явно обозначен как рисунок без рига. `.github/CODEOWNERS`, package-lock и старый геометрический генератор сохранены. 3D skinning, объектное хранение больших ассетов, анимационный GLB, лестницы и инженерные расчёты не реализованы.

Предыдущий этап подготовил русские документы, три проектных skills и конфигурацию официального OpenAI Docs MCP. Конфигурация относится к разработке, а не runtime приложения. Skills применены к этому серверному этапу.

## Проверки

Этап полного роста: локальный мастер собирает 14 костей и weighted mesh, доступны FK-drag и клипы дыхания/приветствия. На реальном рисунке проверены подготовка JPEG, удаление белых просветов, настройка колен, проигрывание/пауза/переход к ключу, поворот предплечья, один undo после drag, импорт/экспорт изображения с сеткой. Повреждённый JSON с неизвестной костью веса отклоняется без замены текущей работы. Найдено и исправлено перетягивание соседней стопы: аналитическая проверка конечного артефакта даёт нулевое смещение правой ноги при движении левой; исправленная поза также отображена в локальном preview. Итоговый пример: 415 вершин, 646 треугольников, встроенный WebP и два clips, около 126 KB JSON. Файл и рисунок остаются локальными и исключены из Git.

Во время повторной браузерной проверки старое нативное подтверждение замены зависло в автоматизации. Новая сборка рига теперь сохраняет предыдущую работу в undo и не вызывает это подтверждение. Отдельный путь локального fixture проверен отображением итогового JSON; последняя сборка/типы прошли. Сквозная генерация через авторизованную страницу и реальную БД по-прежнему не проверена.

## Ограничения

Новая таблица не применялась к рабочей базе; production, Vercel, доставка Brevo и оплата не проверялись.
