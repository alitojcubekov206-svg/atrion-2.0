# Проверка Atrion GLB в Unity

Цель: проверить настоящий объём, размеры, материалы и возможность использовать статическую модель. Экспорт не подтверждает качество выполнения текстового задания.

1. Экспортируйте модель кнопкой GLB. JSON сохраняет редактируемый документ Atrion, а GLB — статическую геометрию и материалы.
2. В проекте Unity установите совместимую с его версией Unity glTFast. Этот импортёр регистрирует `.glb`/`.gltf`; не следует рассчитывать на одинаковый встроенный импорт во всех версиях Unity.
3. Скопируйте GLB в `Assets`, дождитесь импорта и перетащите сцену/prefab на сцену Unity. Проверьте предупреждения в Inspector и Console. См. [официальную инструкцию Unity](https://docs.unity3d.com/Packages/com.unity.cloud.gltfast@6.14/manual/ImportEditor.html).
4. Осмотрите модель с разных сторон. Сравните силуэт, число частей и размеры с заданием; проверьте материалы и прозрачность на выбранном render pipeline. Единицы Atrion — метры, вертикальная ось Y. Проверьте физический размер после импорта.
5. Коллайдеры, игровой контроллер, LOD и анимационный skinning этим экспортом не создаются. Их наличие проверяется отдельно в Unity.

На текущем этапе проверено повторное чтение GLB через Three.js GLTFLoader, наличие mesh/material и конечных координат вершин. Это не проверка в Unity Editor. Реальный импорт в пользовательский Unity-проект пока не выполнен.
