АНИМАЦИЯ СБОРКИ 3D-МОДЕЛИ (Design Engine в кабинете)
===================================================

Что делает
- Когда сгенерирована новая модель (или голосом сказано «собери»),
  она строится по очереди снизу вверх: каждая деталь падает сверху
  на своё место и с лёгкой пружинкой встаёт. Повторяющиеся детали
  (окна в ряд, колонны) появляются одна за другой.
- Вся сборка укладывается примерно в 2,7 секунды, то есть в окно,
  которое уже было выделено под сборку.
- При системной настройке «уменьшить движение» модель появляется
  сразу, без анимации.
- Неоновый редизайн главной и регистрации отменён, сайт выглядит как
  раньше. Прошлый архив atrion-neon-design.zip использовать не нужно.

Изменён один файл: src/frontend/components/three/ConceptViewer.tsx
(основа — коммит d1591fd ветки main).

Как залить (разработчику), из папки проекта:
  git apply assembly-animation.patch
  npm run build
  git add -A && git commit -m "Build-up assembly animation in the 3D viewer" && git push

Или вручную: заменить файл из папки files/ (путь совпадает).

Перед публикацией проверьте сборку (npm run build) и разок
сгенерируйте модель в Design Engine, чтобы увидеть анимацию.
