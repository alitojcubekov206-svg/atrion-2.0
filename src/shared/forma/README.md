# Adapted Furniture Geometry

`furniture.js` was extracted from the user-supplied FORMA project's furniture data and model sections. The user requested its use and adaptation; the original source directory was kept unchanged.

Atrion uses the adapted geometry through its own interface. The source application's interface, images and bundled Three.js build are not used. Atrion's installed `three` package retains its MIT license in `node_modules/three/LICENSE`.

This attribution records source provenance and does not grant a new license to the supplied source project.
