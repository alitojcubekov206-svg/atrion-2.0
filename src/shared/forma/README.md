# Источник геометрии

`furniture.js` выделен из секций `furniture-data.js` и `furniture-models.js` предоставленного пользователем проекта FORMA (`FORMA_compact/FORMA/public/forma/forma.js`). Использование и адаптация запрошены пользователем. Исходная папка сохранена неизменной.

Внешний интерфейс, изображения и поставляемый bundle Three.js не используются. Здесь подключается зависимость `three` Atrion; её лицензия MIT сохранена в пакете `node_modules/three/LICENSE`. Атрибуция источника геометрии не подразумевает выдачу новой лицензии на исходный проект FORMA.
