# Atrion 2.0 — исходники для GitHub

Архив содержит текущие исходники проекта, включая изменения, ещё не записанные в коммит, документацию, тесты, Prisma-схему и библиотеку предметов FORMA. Это снимок рабочей копии от 8 октября 2026 года, без истории Git.

## Что нужно знать о состоянии

Локальная генерация через Qwen3 на CPU подключена, но остаётся экспериментальной. Правильное исполнение любого запроса, реалистичная геометрия и качество уровня Archicad не достигнуты. Примеры ошибок и проверок записаны в `docs/LOCAL_AI.md`. Схема рабочей базы автоматически не обновлялась.

## Запуск

1. Установите Node.js 22 LTS и откройте PowerShell в папке проекта.
2. Выполните `npm ci`.
3. Для локальной нейросети установите CPU runtime и GGUF-модель по `docs/LOCAL_AI.md`. Эти файлы отсутствуют в ZIP и не должны попадать в GitHub.
4. Создайте `.env.local` и добавьте строку `LOCAL_DESIGN_AI_URL=http://127.0.0.1:8081`. Не публикуйте `.env.local`.
5. В одном терминале запустите `npm run design:ai`, в другом — `npm run dev`.
6. Откройте `http://localhost:3000/playground/interior`. Эта песочница доступна в development и позволяет проверять сцену без базы аккаунтов. Для полного приложения с регистрацией и сохранением проектов нужны отдельные настройки из `docs/DEVELOPMENT.md` и `.env.example`.

Без скачивания модели можно запустить `npm run dev` и выбрать «Быстро · по правилам». Это отдельный ограниченный процедурный режим.

## Перенос в свой GitHub

Распакуйте содержимое папки `atrion-2.0` в свой локальный клон репозитория, проверьте `git status` и diff, затем сделайте коммит и push самостоятельно. Архив не содержит `.git`, поэтому не заменяет вашу историю и настройки remote. Не загружайте ZIP вместо исходников, если хотите обычный репозиторий с просмотром кода и сборкой.

В ZIP не включены `node_modules`, `.next`, `.local-ai`, локальные переменные окружения, базы, временные результаты тестов и настройки Git. Файл `.env.example` содержит только примеры настроек.

Проверки кода перед упаковкой: `npm run test:backend`, `npx tsc --noEmit`, `npm run build`. Эти проверки не подтверждают качество каждого ответа нейросети.
