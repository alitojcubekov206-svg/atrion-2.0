# Atrion 2.0

Atrion сейчас объединяет AI Software Architect — технический план программного продукта по идее — и Design Engine для концептуальных 3D-моделей.

Основной фокус по решению пользователя — **2D-риггинг персонажей**: скелет и анимация плоского персонажа. Также в продуктовый объём входят **3D-риггинг** и **создание/дизайн дома**. Добавлены серверные вычисления и API хранения документов; редакторы пока отсутствуют. По запросу пользователя фронтенд не менялся.

## Что уже есть

- Регистрация и вход, JWT-сессия, опциональная проверка email, сброс и смена пароля, удаление аккаунта.
- Проекты: discovery-интервью, технический blueprint, архитектура, БД, API, roadmap, score, критика и риски; AI-эксперты и стартовый код.
- Экспорт blueprint в Markdown и JSON, печать браузера для PDF, публичная ссылка на 30 дней.
- 3D-генерация по описанию, примитивная геометрия и AI-вариант, редактирование деталей, CSG, undo/redo, виды, explode и голосовые команды.
- Экспорт геометрии в GLB, STL, OBJ, PLY и USDZ, выгрузка JSON.
- Настройки языка, голоса, единиц и декоративных эффектов full/lite/off; reduced motion выключает декорации.

Новый [серверный модуль](docs/DESIGN_BACKEND.md) оценивает 2D-скелет и ключевые кадры, позирует жёсткие 3D-детали и строит стены/проёмы из модели комнат. Приватные дизайн-документы сохраняются через отдельный API после применения новой таблицы Prisma. Существующий Design Engine ещё не подключён к этому хранилищу. Дом — эскиз без инженерных расчётов.

## Стек и структура

Next.js App Router, React, TypeScript, Tailwind; Three.js/React Three Fiber/drei; PostgreSQL/Prisma; JOSE и bcrypt; OpenAI-compatible AI с primary/fallback; Brevo для email-кодов.

- `src/app/` — страницы, layouts, metadata; `src/app/api/` — серверные endpoints.
- `src/backend/` — база, auth, AI, квоты, почта и генераторы.
- `src/frontend/` — UI, сцены, CSG, голос, экспорт и настройки.
- `src/shared/` — типы и геометрические функции для обеих сторон.
- `prisma/` — схема; `scripts/` — диагностические проверки; `.github/` — CI и CODEOWNERS.

Frontend не импортирует backend и наоборот. Общие контракты находятся в shared. Серверные Next.js-страницы могут читать backend и рендерить клиентские компоненты. Сохранена [инструкция для фронтенда и бэкенда](<инструкция фронтенд и бекенд>); конкретные утверждения о деплое сверяйте с текущими настройками.

## Быстрый запуск

Нужны Node.js 22 (как в CI), npm и выделенная PostgreSQL development-база. Если `.env` ещё нет, скопируйте [.env.example](.env.example) в `.env`, заполните `DATABASE_URL` и случайный `AUTH_SECRET`.

```powershell
npm ci
npm run dev
```

На выделенной development-базе при необходимости примените схему через `npm run db:push`. Это изменяет базу; не используйте неизвестное соединение. Миграционной истории в этой версии нет.

AI: `OPENAI_API_KEY`, опциональные `OPENAI_BASE_URL` и `OPENAI_MODEL`. Без primary-ключа поддерживаемые генераторы используют demo-результат. Резерв задаётся `AI_FALLBACK_*` и пробуется при распознанных ошибках primary. Доступность моделей и реальные квоты нужно проверять отдельно.

Email: `BREVO_API_KEY`, `EMAIL_FROM_ADDRESS`, `EMAIL_FROM_NAME`. `EMAIL_VERIFICATION_ENABLED` по умолчанию false; включайте после проверки доставки. Сброс пароля требует настроенной почты. `EMAIL_DEV_RETURN_CODE` должен быть false в production: код не ограничивает его только development.

Секреты остаются на сервере. Не коммитьте `.env` или ключи. Полные команды и переменные — в [DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Тарифы и защита

Константы — в [plans.ts](src/backend/plans.ts). Free: 5 существующих проектов, 5 3D-генераций за всё время, 25 AI-запросов в UTC-день. Pro: проекты и 3D без этих количественных ограничений, 300 AI-запросов в день. В UI указаны 200 сом / 30 дней и ручной контакт через WhatsApp (`PAYMENT_WHATSAPP`). Автоматическая платёжная интеграция Finik удалена из актуальной main; процедура выдачи Pro пока не описана приложением.

Auth rate limiter хранится в памяти экземпляра и отключён в development. Приватные project/3D операции проверяют сессию, а при включённом флаге — email. Дневные AI-квоты резервируются в базе; успешный локальный fallback расходует запрос.

## Проверки и проектные навыки

```powershell
npx tsc --noEmit
npm run build
npx tsx scripts/gen-report.ts
npx tsx scripts/csg-smoke.ts
npx tsx scripts/voice-test.ts
```

`tsx` не закреплён как зависимость: `npx` может его загрузить. `gen-report` и `csg-smoke` дают диагностический вывод; это не доказательство визуального качества модели. Скриптов `npm test`/`lint` нет; типы и сборка включены в [.github/workflows/ci.yml](.github/workflows/ci.yml).

В `.agents/skills` находятся `$atrion-2d-rigging`, `$atrion-3d-rigging`, `$atrion-house-design`. GitHub подключение проверено; официальный OpenAI Docs MCP настроен в [.codex/config.toml](.codex/config.toml). Это инструменты разработки, а не runtime-функции Atrion; состояние описано в [TOOLING.md](docs/TOOLING.md).
